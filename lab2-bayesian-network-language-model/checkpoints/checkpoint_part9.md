# Checkpoint Part IX: Generate Text

## Overview & Task Summary
Part IX implements sequential text generation via autoregressive probabilistic sampling. Starting with the initial boundary token $X_1 = \langle\text{START}\rangle$, the model generates subsequent tokens by sampling from conditional distributions:

1. $X_1 \sim P(X_1 \mid \langle\text{START}\rangle)$
2. $X_2 \sim P(X_2 \mid X_1)$
3. $X_3 \sim P(X_3 \mid X_2)$
4. $\dots$
5. Terminate when $X_T = \langle\text{END}\rangle$.

## Evidence & Reproducibility Note

> All 20 generated sentences were recorded using `random.seed(42)`.
> While all transition probabilities are mathematically fixed and exact, exact sampled sentence sequences depend on Python's pseudo-random generator version and may vary slightly across different platform implementations.

### Transition Validity Verification:
Every single transition in the 20 generated sentences exists in the CPT with non-zero probability:
- `sat` $\to$ `on` ($P=1.0$)
- `ran` $\to$ `to` ($P=1.0$)
- `on` $\to$ `the` ($P=1.0$)
- `to` $\to$ `the` ($P=1.0$)
- `the` $\to$ `mat`/`rug`/`park` ($P=0.1667$ each)
