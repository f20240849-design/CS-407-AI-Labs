## Step-by-Step Experiment Reproduction Commands

To reproduce all experimental results, comparison tables, and test logs from a fresh clone of this repository, execute the following commands in sequence:

```bash
# Step 1: Navigate to repository root
cd lab5-search-astar

# Step 2: Run core search test suite (Generates results/test_output.txt)
python3 tests/test_search.py

# Step 3: Run BFS vs A* comparison (Generates results/comparison.md)
python3 src/compare_bfs_astar.py

# Step 4: Run Heuristic Experiments (Generates results/heuristics.md)
python3 src/heuristic_experiments.py

# Step 5: Verify all output files exist and are populated
ls -la results/
```
